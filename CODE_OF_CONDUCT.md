# Código de Conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)
como código de conducta.

En resumen: se espera un trato respetuoso y profesional en issues, PRs y discusiones. No se
tolera el acoso, los ataques personales ni la discriminación de ningún tipo.

Para reportar una conducta inaceptable, escribe al mantenedor a través del perfil de GitHub
[@DanMendezZz](https://github.com/DanMendezZz). Los reportes se tratan con confidencialidad.
